# Kareem Yousry — Interactive Portfolio & Live Project Sandbox

Modern dark-neon portfolio featuring animated SVG visuals and live in-browser simulations for all **KareemYousry-33** GitHub projects:

- **PharmacySystem API (.NET 10 + Clean Architecture)** — Medicines CRUD & search, atomic database transaction invoice POS, customer debt ledger, and global exception handling middleware (`400`, `404`, `500`) + Swagger inspector.
- **SignalR-ChatApp (.NET WebSockets)** — Dual-client real-time chat simulation with `OnConnectedAsync` history replay and `Clients.All.SendAsync` trace.
- **Etman-App / Tabebak (Flutter + AI)** — Multi-role healthcare mobile simulator (`Patient`, `Doctor`, `Pharmacy`) + AI symptom assessment.
- **Enterprise E-Commerce (ASP.NET Core Clean Architecture)** — 🏆 3rd Place award-winning e-commerce storefront with JWT auth toggle and order pipeline.
- **Obour CS Hub** — Academic portal explorer by level and course with Supabase keepalive telemetry.
- **Taskati-App (Flutter)** — Interactive horizontal timeline task manager with `localStorage` persistence.
- **SahltahaLak (PWA)** — Circular SVG study timer + interactive Arabic Dhikr counter.

## Local Preview
Open `index.html` directly in any modern browser or deploy as a static site on Vercel / GitHub Pages.
